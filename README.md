# Vampgram — исправленная сборка 4.0

Все файлы лежат непосредственно в корне проекта. Внутренних папок в ZIP нет.

## Что исправлено в этой версии

- Список диалогов больше не зависит от составного индекса Firestore `members + updatedAt`: поиск выполняется по `members`, сортировка — локально. Это устраняет частую причину пустого списка, когда нужный индекс ещё не опубликован. При ошибке чтения список теперь показывает понятное сообщение и кнопку повторной загрузки, а не маскирует ошибку пустым экраном.
- При создании нового диалога приложение сначала ищет уже существующий диалог с этим собеседником и повторно использует его, даже если у старого диалога нестандартный ID. Это помогает не создавать дубликаты и вернуть старые переписки, если они всё ещё находятся в Firestore и имеют корректный массив `members`.
- Отправка сообщения и обновление карточки диалога (`lastMessage`, `updatedAt`, `unread`) теперь объединены в один атомарный Firestore batch. Сообщение не должно остаться записанным без обновления списка диалогов.
- Голосовые сообщения получили собственный компактный плеер с кнопкой воспроизведения, полосой прогресса, временем и перемоткой. Нативный маленький аудиоконтрол больше не должен выглядеть как серый овал с меню на Android.
- Добавлена расширенная панель оформления: анимированный тёмно-красный фон, включение/выключение эффектов, компактный вид сообщений, звук отправки, размер текста, варианты тёмной темы и сброс настроек. Эти предпочтения сохраняются на устройстве.
- В звонках добавлена буферизация ICE-кандидатов до установки удалённого описания. Это устраняет типичную гонку сигнализации, при которой ранние кандидаты терялись и соединение не устанавливалось.
- Входящие звонки запрашиваются без составного индекса `calleeId + status`, статус фильтруется локально.
- В интерфейсе звонка отображается состояние DTLS-SRTP на основе WebRTC `getStats()`. Медиа WebRTC шифруется транспортом DTLS-SRTP. Отдельное приложение-уровневое E2EE с собственным обменом и подтверждением ключей в этой версии не реализовано; сигнализация (SDP/ICE) хранится в Firestore.
- Версия Service Worker обновлена до `vampgram-shell-v4`, чтобы старый кэш не удерживал предыдущий интерфейс.

## Важное про сохранность диалогов

Новая логика исправляет запрос списка и атомарную отправку. Она не может восстановить записи, которые уже были удалены из Firestore, и не может прочитать документы, если опубликованные правила запрещают доступ. После загрузки проверьте `Firestore → Rules` и разверните правила, приложенные в архиве. При ошибке доступа приложение теперь покажет её в самом списке диалогов.

## Файлы и хранилище

- Firebase Authentication и Cloud Firestore.
- Firebase Storage и `storage.rules` не добавлялись.
- Большие фотографии автоматически уменьшаются и сжимаются до допустимых значений Firestore.
- Документы, голосовые и видео ограничены техническим лимитом около 6 МБ на файл. Для больших медиафайлов требуется отдельное объектное хранилище/CDN.

## Звонки и безопасность

WebRTC использует DTLS-SRTP для шифрования аудио/видео-трафика между браузерными узлами. Наличие зелёного статуса показывается только после того, как `RTCPeerConnection.getStats()` сообщает `dtlsState: connected`. Это не следует путать с самостоятельным E2EE-протоколом с проверяемыми ключами. Для устойчивой работы звонков через сети с жёстким NAT может потребоваться TURN-сервер; в текущей конфигурации используются публичные STUN-серверы.

## Публикация

На присланном скриншоте приложение открыто через GitHub Pages (`github.io`). Для такого размещения:

1. Распакуйте архив и загрузите **все 15 файлов прямо в корень GitHub-репозитория**, где включён GitHub Pages. Не создавайте для них отдельную папку.
2. Сделайте commit/push. После публикации обновите страницу Vampgram.
3. Отдельно проверьте Firebase Authentication → Sign-in method → Email/Password.
4. Опубликуйте правила и индексы Firestore из этого архива через Firebase Console → Firestore → Rules/Indexes либо Firebase CLI:

```bash
firebase deploy --only firestore:rules,firestore:indexes
```

Не используйте `firebase deploy --only hosting`, если сайт продолжает размещаться на GitHub Pages. Для Firebase Hosting эта команда подходит только после переключения хостинга на Firebase.

После обновления закройте установленную PWA и откройте сайт заново, чтобы Service Worker `vampgram-shell-v4` заменил старый кэш. Если старая версия остаётся, очистите данные сайта/кэш Service Worker в браузере и перезагрузите страницу.

## Установка

- Android: Chrome → меню → Установить приложение / Добавить на главный экран.
- iOS: Safari → Поделиться → На экран «Домой».
- ПК: Chrome или Edge → Установить Vampgram.

Это PWA-сборка. APK-файл в архиве не скомпилирован.
