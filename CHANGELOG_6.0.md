# Vampgram 6.0 BLOODLINE — Change Log

- Added social feed with text and optimized image/video posts.
- Added likes, comments, saved posts, edit/delete own posts, and post reports.
- Added Communities catalog, creation, joining, member posts, and leaving for non-owners.
- Added in-app notifications for likes, comments, and new followers.
- Added user follow/unfollow relationships and follower counts on profiles.
- Added profile status text.
- Added JSON export for profile, owned posts, and a bounded recent-chat archive.
- Added in-app Firebase and connectivity diagnostics.
- Added bounded global search across recent messages in loaded chats.
- Added previous-message pagination for older conversation history.
- Extended Firestore Rules for new feed/media/community/follow/notification collections.
- Added the composite index used by backup export.
- Bumped PWA shell cache to `vampgram-shell-v6-0-0`.
- Preserved existing conversation, story, channel, profile, and media collections.
