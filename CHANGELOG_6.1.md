# Vampgram 6.1 DIAMOND

- Главный экран переделан в вертикальную ленту коротких видео и публикаций с прокруткой по одному посту, авто-паузой роликов вне экрана и управлением звуком.
- Добавлена фиксированная нижняя навигация: Лента, Чаты, Создать, Каналы, Клубы, Профиль.
- Обновлён визуальный стиль: прозрачные diamond/glass панели, гранёные акценты, мягкое свечение, безопасные отступы для Android.
- Каналы: читать могут подписчики, писать — только владелец и назначенные администраторы. Владелец назначает админов по @username или email. Ограничение дублируется в Firestore Rules.
- Чаты: меню действий, персональная очистка истории и скрытие диалога из списка. Общие документы и сообщения не удаляются — у других участников история остаётся.
- Добавлены правила для `users/{uid}/chatPrefs/{conversationId}`.

## Установка
1. Сделай резервную копию текущего проекта и данных.
2. Замени файлы из архива.
3. Опубликуй новый `firestore.rules` в Firebase Console.
4. Обнови PWA-кэш: полностью закрой установленное приложение/вкладку, затем открой Vampgram заново. Если старая оболочка сохраняется, очисти кэш сайта в браузере.
5. Проверь тестовыми аккаунтами: публикации в ленте, лайк/комментарий, личный чат, очистку и скрытие, публикацию владельцем канала и отказ обычному подписчику.

Firebase Storage rules не добавлялись. Полноценное тестирование с живым проектом Firebase требует запуска в твоём окружении.
